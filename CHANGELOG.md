# FocusPin changelog

## V2
- Separate normal-size expanded window with Remaining and Completed tabs and summary counts.
- Priority sorting, due date/time, overdue highlighting, categories, task notes, completed-task history.
- New/edit dialog, nested subtasks with independent checkbox state and progress indicator.
- Mouse inactivity alert settings for duration, color, flash speed, three audio profiles, volume, repeat interval; 8-second instant test and snooze.
- One-task focus mode; start, pause, resume, exit; recorded sessions and 7-day productivity graph.
- Daily, weekday, weekly, and monthly recurring tasks, creating a future occurrence upon completion without hiding history.
- Search and filters; 30-step undo; JSON backup/restore with pre-restore safety copy and CSV export.
- Windows Ctrl+Alt+F unlock/show and Ctrl+Alt+T quick add; click-through automatically unlocks after 10 minutes and is reset at startup.
- V1 save migration with a one-time backup at `state.v1.backup.json`.

## V2 — Soft Studio UI refresh (2026-10-09)
- Replaced dark indigo surfaces with warm ivory, pale rose, soft mauve typography and subtle rounded cards.
- Reduced dashboard row clutter with contextual task menus while preserving editing, focus, restore and delete.
- Simplified the mini-note copy, focus controls, task editor and reminder settings.
- Added cohesive local SVG illustrations and a GitHub-ready README.
- No changes to state storage path or existing task schema.
- Task editor now starts with only the task name, priority and category. Advanced fields live under a collapsible "More details" section and reopen automatically on tasks that already use them.
- Updated application icon to match the warm pink/cream theme.
